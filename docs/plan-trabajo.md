# Plan de trabajo

Secuencia inicial sugerida para cuatro semanas, ajustable a las fechas del equipo:

1. Preparar Odoo 20, activar Ventas y Catálogo, crear datos demostrativos y validar JSON-2 con credenciales locales.
2. Completar API .NET: contratos, manejo de errores, autenticación, categorías, órdenes e historial autorizado.
3. Completar Flutter: navegación, catálogo filtrable, carrito, acceso del cliente, confirmación e historial.
4. Ejecutar pruebas unitarias sin red, integración API–Odoo y aceptación extremo a extremo; cerrar guía, matriz RF/CA/pruebas y evidencias.

La integración con la instalación del equipo es una dependencia temprana. No se deben reutilizar los IDs del PDF técnico, porque corresponden únicamente a la base de datos de demostración de ese documento.
